Windows BAT Toolkit
===================

40 separate ready-to-use .bat files for Windows laptop/PC.

Important:
- Files that modify Windows/network settings should be run as Administrator.
- Read the command shown before running it.
- Backup/restore and disk commands should be used carefully.
- These scripts do not bypass passwords, licensing, security controls, or antivirus protections.

Run:
1. Extract the ZIP.
2. Right-click a .bat file.
3. Choose "Run as administrator" when required.
